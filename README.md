# BFSI_Loan_Portfolio_-_Risk_Collections_Analytics
This project analyzes a loan portfolio to understand credit risk, loan defaults, borrower characteristics, and collections performance. The data was cleaned and validated using Python/Pandas, with additional transformation and data preparation performed in Power Query. An interactive Power BI dashboard was developed using DAX to track key KPIs such as total loans, loan amount, default rate, average DTI, payments, principal received, recoveries, and late fees. The dashboard provides insights into risk grades, loan purposes, borrower risk factors, delinquency, and collection trends, helping demonstrate how data analytics can support credit-risk monitoring and portfolio management.
